📖 PageTrace 功能与快捷键指南
✨ 一、油猴脚本浮动按钮（任意网页右下角）
操作方式 功能描述
鼠标左键 快速复制当前网页标题与网址 (Title + URL) 到剪贴板
鼠标右键 直接保存当前网页标题与网址 (Title + URL) 至云端
Ctrl + 左键 在前台新标签页中打开云端速记看板
Ctrl + 右键 展开速记卡片，可输入备注并保存同步至云端
Ctrl + Shift + H 隐藏/恢复浮动按钮
悬停鼠标 弹出提示框，每行一条简要操作提示
⌨️ 二、速记输入框操作逻辑（插件与看板一致）
按键组合 动作
Enter 文本换行，方便编写多行备注或分段
Shift + Enter / Ctrl + Enter 保存速记到云端并关闭窗口
Esc 取消/收起当前速记弹窗
🖥️ 三、云端速记看板页面快捷键
按键 功能
/ 快速呼出搜索框，输入文字即时过滤全部笔记
N 快速打开新建速记弹窗
D 切换深色 / 浅色模式
? 快速打开使用文档与快捷键说明
Esc 关闭搜索框、新建弹窗、编辑弹窗或文档，清除搜索筛选
