# 浏览、缓存与同步设计

整理日期：2026-10-18。提取自截至 2026-10-15 的实施记录，最近记录的发布版为 1.13.3；本次没有重测或重新确认线上版本。原始问题、方案取舍、测试和发布证据见[历史审查与实施记录](../review/implementation_plan.md)。

## 按月浏览与缓存

- 默认按本地时区的创建时间监听当前月：包含月初、不包含下月月初；编辑时间不改变所属月份。切月关闭旧监听，忽略晚到的旧范围和旧账号回调。
- 缓存按账号、查询范围及时间边界分区，历史缓存最多保留 12 个范围并按容量淘汰，旧全量缓存一次性兼容拆分。
- 油猴保存成功后保留文档 ID 与服务端版本，通过共享记录和月份轻量索引桥接当前范围正文。管理页先合并缓存和共享新增笔记，再展示首屏；相同内容不重建列表。
- 月份导航允许空月；未加载不显示为零，完整加载的空月才显示零。全年及全历史由用户显式选择，最早/最新年份查询延迟到打开年份选择器。

## 搜索与批量操作

- 输入非空搜索词才开始全历史加载，后续关键词复用查询和数据；未完成或失败不报告完整的零结果。退出搜索恢复原月份。
- 全文搜索数据不写入普通启动缓存；首轮全局搜索仍承担历史全文读取，不宣称已实现云端全文索引。
- 回收站独立加载全历史删除记录，未完整加载时禁止清空；确认后重查并按 400 条分批删除。
- “复制全部”等待当前范围完整加载，复制完整范围，不能只复制当前显示的 50 条。跨月操作更新对应缓存，缓存失败不否定已确认的云端写入。

## 编辑和同步反馈

- 共享网页的同步提示位于 PageTrace 标题右侧，普通加载显示“同步中…”，单行省略并保留完整提示；完成后隐藏，不再独占导航上方一行。
- 等待服务器 15 秒后提示本地缓存或暂无缓存；保留原监听，恢复后继续同步。账号、范围切换和明确错误取消旧计时器。
- 油猴编辑器获焦时隔离宿主页面的相关编辑事件，同时保留浏览器默认粘贴和普通编辑行为；输入法组合中的 Enter 不提交，普通页面输入框不受影响。

## 尚未实施的范围

正文版本目录下载继续暂缓；云端全文索引、所有旧客户端历史改动的即时计数及记录末尾的触屏字号/密度、导航留白和 Android 字体适配建议不视为已完成。既有自动测试和历史发布结果仍以原始记录的具体版本和环境为准。

## 年月数量汇总（1.16.0，2026-10-28）

- 数量统计包含账号全部有效笔记，按日历本地时区划分年/月并排除回收站，年度与月份合计核对一致。个人数量明细、账号标识与迁移记录仅保留本地，不进入公开发布包。
- 统计独立保存到用户自己的 `calendarCounts/{timezoneKey}` 文档，配合按 UID/时区隔离的本地缓存。已获准并应用最小所有者规则；原笔记权限不变。菜单直接读取汇总，不依赖历史正文是否已加载；未知和失效月份仍显示未加载。
- 使用现有登录和 SDK，REST 聚合只返回数量，删除记录仅投影日期；历史摘要长期复用，实际新增/删除/还原重算受影响月，普通内容编辑不重算。当前月在连接、回到前台及恢复网络时节流刷新，失效月份保留断点。未更新的旧客户端无法主动维护新摘要，其历史变动在对应月份正文重新加载时核对修正。
- Web/Android 资源清单包含共享模块，部署使用 `dist/web-<VERSION>` 白名单包。安装覆盖原包保留用户数据；源、构建、发布和手机安装的完成状态分别记录于维护中心当前版本账本。

## 饭否迁移与批量导入：排障经验（2026-10-27）

本节记录本次实际遇到的问题，供后续任务复用；不表示迁移及年月统计已全部完成。实际进度以原项目 `results/fanfou_migration_20261026/import_status.json`、成功日志 `import_ack.jsonl`、样本核对结果 `import_verification.json` 为准，后续年月统计仍遵守[实施计划](../review/implementation_plan.md)的执行前提。

- **目标账号不等于已登录。** 页面上的“目标账号”是静态配置。只有正常 Google 登录后显示“已连接”，服务端核对邮箱及 UID 通过，再点击“开始导入”且实时状态变为 `running`、成功数量开始增加，才表示导入已启动。进程存在、页面打开或旧日志显示成功，都不能代替本批的实际状态。
- **登录弹窗关闭不等于账号失效。** `auth/popup-closed-by-user` 只说明弹窗在认证完成前已关闭，不能据此认定账号被封、用户违规或一定由用户主动关闭。避免连续点击产生多个授权窗口；读取实际页面错误，正常完成账号选择及回调，不把“等待登录”当作成功，也不在认证尚不明确时改走直接启动接口。
- **浏览器连接标识不是固定值。** 本次 Chrome 的数字标识曾在不同会话中变化，旧标识可能指向内置浏览器；`Debugger unattached` 也可能是旧标签页控制绑定失效。先用当前浏览器清单定位 Chrome 或按受支持的浏览器名称操作，不能照抄历史数字 ID。必要时在同一已选浏览器打开新的临时本地页；同一路径失败两次后停止盲目重试，转用已支持的恢复方法或报告具体手动操作需求，不读取浏览器隐藏凭据。
- **授权成功不代表每个接口都可用。** 自有 Share to Fanfou 应用曾显示 OAuth 授权成功，但消息接口仍返回 `401 参数错误`；该应用当时的具体限制没有确认。经用户明确授权后，使用 Nofan 的注册应用及 `fanfou-sdk@6.0.0` 成功读取完整历史。先验证账号、少量消息和历史尾页，再启动完整导出，不因 401 就重设密码或虚构权限原因。饭否当时要求 OAuth 签名中的地址使用 HTTP scheme，但传输仍保持 HTTPS；使用 SDK 的签名钩子兼容，不能关闭 TLS 校验。
- **批量接口权限错误先检查调用方式。** 本次 `documents:batchWrite` 返回 403，而正常 Firebase 用户登录配合 `documents:commit` 成功写入；复用已验证的客户端提交路径。这个观测不能扩展为所有 403 的统一原因，更不能据此放宽 Firestore 规则或换用管理员权限。
- **TLS EOF 是连接中断，不是用户违反规定。** `[SSL: UNEXPECTED_EOF_WHILE_READING]` 表示加密连接尚未读取完成就意外结束，可能涉及服务器、代理或网络；单条错误不能确定哪一端负责。现有脚本对明确的临时 TLS／连接中断仅延迟后重试一次；额度、认证、权限及证书校验错误不在此重试。保持证书验证，不为偶发中断重配网络或反复重启整批任务。
- **空数组的传输格式差异曾触发误报。** Firestore 返回空数组时可省略 `arrayValue.values`，与发送时的显式空列表表达相同值。本次来源字段核对失败就是这个原因。使用 `decoded_value()` 比较数组、映射、空值和时间的实际含义；保留真实内容不一致的报错，不能只把核对全部关闭。修正后重新读取少量已确认成功的近期、历史及 FaWave 样本，实际内容一致才记录核对通过。
- **配额限制与网络故障分别处理。** `HTTP 429: Quota exceeded` 出现后停止本批，保留断点，不循环重试。[Firestore 免费额度](https://firebase.google.com/docs/firestore/quotas#free-quota)为每天 20,000 次文档写入，日常新增、编辑也会占用；按太平洋日期计算额度日，不把北京时间 15 点写成全年固定重置时刻。默认每额度日迁移最多 19,000 条，留出日常余量。同日额外重试或最多 1,000 条补传只在用户明确授权后启用，并检查当天已成功数量及一次性标记；剩余额度不保证恰有 1,000 条。获准补量时逐条创建，首个额度错误即停止，避免大批原子提交因剩余额度不足而整体失败。
- **断点和防重依靠消息 ID，而不是重新导出。** 固定文档 ID `fanfou_<原消息ID>`，成功后逐条写入 `import_ack.jsonl`；下一批先排除这些 ID，并保留 `currentDocument.exists=false`。如果提交响应丢失而服务端可能已经写入，重试出现 409 时读取已有记录核对原消息 ID 后跳过，不能覆盖，也不能只按 URL 去重，因为不同时间可以合法重复分享同一链接。
- **区分本批完成、全量完成与回调。** `ready` 表示未启动，`running` 才是执行中；`batch_complete` 只表示本批结束，`complete` 才可作为全部导入及后续统计的前提。先确认本次状态和进程，再启动绑定本聊天的完成回调；避免让旧批次的终态误触发新批次回调。程序负责等待和日志，模型不反复轮询；完成或失败后读取实际数量、核对必要样本、关闭临时服务。每次手动恢复只消费其明确授权，不自动扩大到更多同日批次。

后续复用入口：`scripts/fanfou-import.py`、`scripts/fanfou-import-callback.mjs`、`tests/fanfou-import.test.py`。权限、账号、配额或关键方案确需用户决定时，把具体需求一次说明；已授权且已有明确方案的局部修复直接执行，不重复索要同一授权。
